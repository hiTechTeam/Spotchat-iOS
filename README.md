# Spotchat iOS

Spotchat — постоянные личные чаты с доставкой через Bluetooth без интернета
и дополнительной доставкой через Nostr, когда интернет доступен.
Собственный центральный сервер не требуется; Nostr использует независимые relay-серверы.

- Кнопка **+** открывает контакты: QR, люди рядом и приглашение через системное меню.
- Identity и история сохраняются независимо от временных BLE ID. Приватные ключи — в Keychain;
  контакты, история и очередь — в зашифрованном файле с защитой iOS.
- Если получателя нет рядом, можно написать сообщение: оно останется в очереди,
  отправится через Nostr либо через совместимые Spotchat-устройства при последующих встречах.
- «Передаётся» означает передачу в транспорт/mesh, «Доставлено» — подписанное подтверждение
  получателя после сохранения. «Прочитано» — открытый активный диалог на устройстве получателя.
- Приглашения от новых пользователей нужно принять в разделе «Контакты».
- Обычные контакты iPhone используются только для системного приглашения. Телефонные номера
  не являются Spotchat identity и не загружаются в сеть.

Текущие компоненты UI, BLE/Noise, аватары и medium-карточка сохранены.
Архитектура, ограничения и проверка: [offline-first](docs/spotchat/OFFLINE-FIRST.md).
macOS-схема остаётся исходным Bitchat и не является целью этой реализации.

## Открыть и собрать

Требуется Xcode. Проект использует iOS 16.0 как минимальную версию.
Первое разрешение Swift-пакетов требует интернета; это требование сборки,
а не будущего Bluetooth-чата.

```sh
open bitchat.xcodeproj
```

Выбрать схему **Spotchat** и iOS Simulator. Внутренние имена проекта, модулей
и файлов `bitchat` сохранены для удобного сравнения с upstream.

Сборка из терминала (UDID: `xcrun simctl list devices available`):

```sh
xcodebuild -project bitchat.xcodeproj \
  -scheme Spotchat -configuration Debug \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,id=SIMULATOR_UDID' \
  -derivedDataPath .DerivedData \
  build
```

Для обычного запуска сохраните стандартную подпись симулятора: без неё
системный Keychain может отказать в доступе. Модульные тесты используют
отдельные тестовые хранилища и не читают личные ключи.

## Подготовка подписи для физических устройств

```sh
cp Configs/Local.xcconfig.example Configs/Local.xcconfig
```

Указать свой `DEVELOPMENT_TEAM` в локальном файле. Debug его автоматически
подключает; файл исключён из Git. Release намеренно не использует локальные
Debug-настройки. Команда исходного автора Bitchat удалена из общей конфигурации.

Схема **Spotchat** не собирает и не встраивает share extension и не запрашивает
App Groups, поэтому подходит для Personal Team. Сами upstream-targets сохранены.
Для каждого нового тестового телефона Xcode должен обновить provisioning profile.
Пример сборки с регистрацией подключённого устройства:

```sh
xcodebuild -project bitchat.xcodeproj -scheme Spotchat \
  -configuration Debug -destination 'platform=iOS,id=YOUR_DEVICE_UDID' \
  -derivedDataPath .DerivedData \
  -allowProvisioningUpdates -allowProvisioningDeviceRegistration build
```

На устройстве необходимы Developer Mode, доверие компьютеру и профилю
разработчика, а при первом запуске — разрешение Bluetooth.

## Проверить чат на двух iPhone

1. Установить **Spotchat** на оба iPhone и открыть приложения рядом друг с другом.
2. Ввести разные имена через кнопку профиля справа сверху.
3. Через **+ → Рядом** сохранить друг друга либо обменяться QR-кодами.
4. Открыть постоянный диалог и отправить текст в обе стороны.
5. Проверить подтверждения доставки/прочтения. Перезапустить приложение:
   контакт и история должны остаться.
6. Выключить Wi-Fi и мобильные данные, оставив Bluetooth включённым, и повторить.
7. Разнести телефоны: новое сообщение остаётся в очереди. Вернуть устройства рядом:
   сообщение автоматически доставляется в тот же диалог.

Для store-and-forward нужен третий iPhone с этой версией Spotchat: сначала он
встречает отправителя, затем получателя; отправитель и получатель не встречаются.
При обратной встрече курьер переносит подтверждение доставки. Для отдельной
проверки Nostr включите интернет на двух телефонах, отключите Bluetooth и повторите обмен.

Первый тест проводится при открытых приложениях. Фоновую доставку iOS нельзя
считать гарантированной. Текст ограничен **4096 UTF-8 байт**, очередь доставки —
24 часами; истечение срока не удаляет сообщение из истории.

Старые протоколы испытаний BLE: [этап 2](docs/spotchat/STAGE2.md).
Актуальные проверки: [offline-first](docs/spotchat/OFFLINE-FIRST.md).
